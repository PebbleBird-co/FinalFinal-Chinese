# 0009：报告 UI 使用进程内状态边界

## 状态

已采纳（Phase 7）

## 决策

Phase 7 使用 Zustand 在 Renderer 进程内保存最近一次 `ScanResult`。扫描成功后自动进入 `/report/overview`，报告的总览、时间线、家族、风险与文件档案页面都只从该结构化结果派生。

刷新页面、重启应用或直接访问报告路由且没有结果时，显示可恢复的空状态。扫描中与扫描错误通过同一 store 暴露统一加载和错误状态。

## 理由

- 不新增文件系统能力，保持只读扫描的安全边界不变。
- 不在用户项目目录或 Electron `userData` 中提前写入数据。
- 报告页面可独立测试，且无需重复计算后端分析。
- 本地 JSON 持久化属于 Phase 8，与用户纠正记录一起实现更容易维持一致性。

## 范围限制

- Phase 7 不保存历史报告。
- Phase 7 不提供设置主版本、修改父边、拆分或合并家族等纠正操作。
- “导出报告”只显示禁用入口，实际 PDF 导出留到 Phase 9。

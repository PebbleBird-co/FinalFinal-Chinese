# 0011：由主进程生成有界的可打印报告

## 状态

已采纳（Phase 9）

## 决策

PDF 导出只接收结构化的 `ScanResult` 与纠正数量。报告 HTML 在 Electron 主进程内生成，由隐藏的隔离窗口通过 `webContents.printToPDF` 转换为 A4 PDF。Renderer 不能提供任意 HTML，也不能指定输出路径；目标路径必须来自系统保存对话框。

打印版对可能很长的列表设置稳定上限：正式版本候选 3 项、事件 30 项、风险 50 项、家族 100 项、活动柱 48 个。发生截取时，报告明确显示省略数量，完整分析结果仍保留在应用内。

## 理由

- 结构化输入缩小 IPC 与打印边界，避免 Renderer 注入任意打印内容。
- 系统保存对话框使导出成为用户明确授权的写入，不扩大对调查目录的写权限。
- 有界列表让大项目的打印时间、内存占用和页数保持可预测。
- 省略提示避免把打印版摘要误解为完整数据集。

## 范围限制

- PDF 不包含文件正文，也不调用外部 AI API。
- PDF 是静态调查摘要，不提供附件、交互图表或可编辑表单。
- 导出不会移动、重命名、覆盖或删除被调查项目中的原始文件。
